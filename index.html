Introduction to Important Projects

These projects reflect a mix of academic coursework, programming practice and multidisciplinary teamwork.

1. CampusWatt — Smart Campus Energy Monitoring

CampusWatt is a smart hostel and classroom energy-monitoring prototype designed to track live power consumption and circuit status across buildings. It combines a React web dashboard with distributed ESP32 room nodes equipped with current sensors, voltage references, PIR motion detectors and automated safety cut-off relays.

The system is designed to identify situations such as possible circuit overloads or appliances left running in unoccupied rooms. Based on its monitoring logic, it can trigger an automatic power cut-off to help improve safety and reduce energy waste. The project brings together embedded systems, sensor-based monitoring and a web interface in a multidisciplinary solution.

React DashboardESP32Current & Voltage SensingPIR SensorsRelay AutomationIoT

2. Heat Transfer Simulation Along a Rod

This project uses GNU Octave to simulate one-dimensional heat transfer along a rod. The heat equation is solved numerically using the finite-difference method. Temperature profiles are plotted at different time intervals to observe how heat spreads along the rod while the ends are maintained at zero temperature.

GNU OctavePartial Differential EquationsFinite-Difference Method

3. Python Project — Guess the Number Game

This command-line game generates a random number between 1 and 100. The player chooses an easy or hard level, which determines the number of attempts available. After each guess, the program gives a hint indicating whether the secret number is higher or lower. This project helped me practise loops, conditional statements, user input and Python's random module.
