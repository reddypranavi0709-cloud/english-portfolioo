# Pranavi Reddy — Final Student Portfolio

A responsive student portfolio in a pastel beige theme.

## Sections
A. Introduction to My Portfolio
B. Introduction to Important Projects
C. Important Classes Attended / Courses
D. Publications / Writing Assessments — intentionally omitted as requested
E. Short Resume — profile, an educational qualifications table (BTech, Class XII, Class X and JEE Main percentile), technical skills, strengths and areas of interest. The separate Achievements section has been removed.

## Projects included
1. CampusWatt — Smart Campus Energy Monitoring (includes the supplied system architecture/layout image)
2. Heat Transfer Simulation Along a Rod (Octave code and simulation screenshots)
3. Python Project — Guess the Number Game (source code and console screenshots)

The Array-Based Character Stack and Personal Portfolio Website project entries have been removed.

## Open the website
1. Extract this ZIP file.
2. Open the `pranavi_portfolio_final` folder.
3. Double-click `index.html` to open it in Chrome.

No installation is required. An internet connection is needed only for the online fonts.
